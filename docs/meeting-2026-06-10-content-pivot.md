## 1. 무대 패널 폐기 — 근거

운영자 질문: "왼쪽 무대 패널이 무의미하게 트래픽만 늘리는 것 아닌가?"

사실 정정 먼저: **무대 패널은 LLM 트래픽과 무관하다.** 무대가 쓰는 건 정적 이미지 자산 — 초상 `public/personas/portraits/*.webp`(1.2MB) + 배경 `public/stages/backgrounds/*.webp`(6종). 토큰을 추가로 먹지 않는다. 늘어나는 비용은 ① 첫 로딩 네트워크 대역폭 ② 화면 가로폭 점유 ③ R-1.5b(웹 3패널) 구현·유지보수다.

그럼에도 폐기가 맞다. 콘텐츠/인사이트로 무게중심을 옮기는 방향에서 무대 패널은 **순부채**다:

- 인사이트 기여 0 — 인물 그림은 "누가 말하는가"를 보여줄 뿐, "무엇을 깨닫는가"에 기여하지 않는다.
- 중복 — 화자 식별은 피드 카드의 아바타·이름·시그니처·발화 글로우로 이미 충분. 무대는 그걸 한 번 더 그린다. R-1에서 폐기한 "자기 자신과 경쟁하는 연출"의 잔재.
- 매몰비용 0 — R-1.5b는 착수 전. 지금 접으면 버릴 코드가 없다.

**결정**: 무대 패널(StagePanel/DebateStage 계열) 폐기. 웹은 **피드 + 디렉터 콘솔 2단**으로 화면을 꽉 채운다. 인물 연출은 피드 카드 아바타·시그니처·사운드로 일원화. `public/personas/portraits`는 카드 아바타·드로어에서 계속 쓰이므로 자산은 유지, *무대 렌더 경로만* 제거.

→ `workorder-layout-R15-conversation-first.md`의 R-1.5b를 **R-1.5b′(무대 없는 2단)**으로 갱신 (그 워크오더 상단에 본 결정 반영 메모 추가).

## 2. 보여주기 트랙 동결 — P-B 연기

운영자 한 줄("보여주기→콘텐츠")의 직접 귀결:

- **P-B(moveType 연출)** — 반격 펄스·크리티컬·질문 비네트는 *보여주기*다. 인사이트에 직접 기여하지 않는다. **인사이트 트랙(I) 뒤로 연기.** 단 moveType *스키마*(데이터로서의 충돌 분류)는 인사이트에 쓸모가 있을 수 있어 I 트랙 설계 중 재평가.
- **⑤-5 게임화 잔여**(시그니처 추가분·게이지·컷신) — 동결 유지.
- **R-3′ 항로 뷰** — 인사이트성이 있으나(선택의 기록) 보여주기 비중도 커서, I 트랙 뒤 재론.

원칙 추가 (6번):
> **보여주기는 인사이트를 전달할 때만 정당하다.** 한 픽셀의 연출이 사용자의 깨달음에 기여하지 못하면 그것은 부채다.

## 3. 인사이트 트랙(I) 신설 — 운영자 3선 모두 채택

운영자가 인사이트 투자처로 셋 다 골랐다. 입력→토론→결론의 세 길목에 하나씩 놓이므로, 셋이 경합이 아니라 파이프라인을 이룬다:

```text
[입구] I-1 고민 다듬기      → 입력 품질이 토론 품질을 좌우 (가장 앞단 지렛대)
   │
[토론] I-2 인사이트 마킹     → 지나가는 통찰을 사용자가 붙잡음 (핀)
   │
[결론] I-3 결정 지도 심화    → 붙잡은 것 + 갈림을 결론으로 빌드
```

### I-1 — AI 가이드 고민 다듬기 (1순위)

현재 빈 1000자 텍스트박스는 "내가 뭘 고민하는지"를 사용자가 스스로 정리해 쏟아내야 한다 — 인지부하 크고, 입력이 얕으면 토론도 얕다. 전환: 한 줄 입력 → AI가 **날카로운 역질문 2~3개**(진짜 결정 지점 / 시도한 것 / 제약·기한)를 던지고, 사용자가 답하며 concern이 저절로 풍부해진다. 로드맵의 잠든 "개선 2b"를 격상. 무료 LLM 호출 1회(가벼움). **프롬프트 본문이 품질의 핵심 — Fable 박제.**

### I-2 — 토론 중 인사이트 마킹 (2순위)

사용자가 지나가는 발언을 핀(저장)하고, 그 핀이 결론(I-3)의 입력이 된다. 로드맵 트랙 ②의 "발언 핀 → 결론을 핀에서 빌드"가 출처. LLM 호출 0(상호작용만). 게임 루프의 "선택의 기록" 일부를 인사이트 쪽으로 흡수.

### I-3 — 결정 지도 심화 (3순위)

트랙 ②(결정 지도)는 출하됐으나, 핀(I-2)·풍부해진 concern(I-1)을 입력으로 받으면 결론의 정밀도가 올라간다. "끝내 갈린 것"의 근거 추적 강화. I-1·I-2 출하 후 프롬프트 재박제.
