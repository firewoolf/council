# 에셋 사양서 — ⑤-5h 토론 무대 (David 생성용)

> 작성: Opus / 생성: David (Nano Banana 등)
> 용도: 비주얼 노벨식 토론 무대 — 선택 배경 위에 대형 반신 캐릭터.
> 두 묶음: ① 캐릭터 반신 **투명 컷아웃** 10개, ② 장면 **배경** 6개.

---

## 핵심 원칙 — 왜 투명 컷아웃인가

배경을 *사용자가 갈아끼우므로*, 캐릭터에 배경이 박히면 안 된다. 기존 `portraits/*.webp`(서재·모니터 박힘)는 무대에 못 쓴다. **알파 투명 PNG/WebP** 로 새로 만든다. 배경은 별도 레이어.

합성 구조: `[배경 이미지]` ← 뒤, `[캐릭터 컷아웃]` ← 앞(하단 정렬), `[대사 박스]` ← 최상단.

---

## ① 캐릭터 반신 컷아웃 (10개)

### 공통 규격

- **형식:** PNG (알파 투명) 권장. WebP-alpha 도 가능. **배경 완전 투명** — 환경·바닥그림자·소품 금지.
- **프레이밍:** 허리~머리(반신). 약 3/4 측면, 시선은 화면 *안쪽(중앙)* 을 향함.
- **캔버스:** 세로 1024×1536 (2:3). 인물 가로 중앙. **머리 꼭대기를 캔버스 상단 ~12% 지점**, 허리에서 컷. → 10명 *머리 크기·눈높이 일치* (화자 전환 시 얼굴이 튀지 않게). ★ 가장 중요.
- **조명:** 균일하고 부드러운 정면광. 한쪽 환경색이 박힌 강한 그림자 금지(배경 바뀌면 어색).
- **스타일:** 기존 초상화의 유화/painterly 톤과 통일(둘 다 보일 수 있음). 사실적, 게임 무장 시뮬 톤.
- **표정/포즈:** 말하는 듯한 생동감(손짓 1개 정도 OK, 단 반신 프레임 안). 캐릭터 성격 반영.
- **네이밍:** `public/personas/cutouts/{archetypeId}.png` — id 정확히 일치.

| archetypeId | 이름 | 역할 | 룩/포즈 힌트 |

| `jobs-designer` | 잡스형 디자이너 | UX 디자이너 | 검은 터틀넥, 미니멀, 한 손 제스처(검지), 확신에 찬 눈 |

## ② 장면 배경 (6개)

### 공통 규격

- **형식:** WebP (불투명). 1920×1080 (16:9).
- **구도:** **중앙이 비어야 함** — 캐릭터가 화면 중앙~하단을 차지하니, 시각 초점·디테일은 *좌우/상단* 으로. 중앙 하단은 단순하게.
- **톤:** 살짝 채도 낮추고 소프트 포커스(피사계 흐림) — 캐릭터가 앞으로 튀어나오게. 너무 화려하면 캐릭터를 잡아먹음.
- **조명:** 따뜻한 중립. 6장 *광원 방향 통일*(캐릭터 정면광과 안 싸우게).
- **네이밍:** `public/stages/backgrounds/{id}.webp`.

### 6장 (id · 라벨 · 설명)

| id | 라벨 | 장면 |
|---|---|---|
| `meeting-room` | 회의실 | 모던 회의실, 긴 테이블·유리벽·도시 야경 살짝. COUNCIL 기본값. |
| `office` | 사무실 | 오픈 오피스, 흐릿한 책상·모니터, 활기. |
| `study` | 서재 | 책장·우드톤, 차분·사색. |
| `courtroom` | 법정 | 우드 패널·국기/엠블럼 흐림, 격식·대치. (법률 분야) |
| `cafe` | 카페 | 따뜻한 조명·창가, 편안한 대화. |
| `studio` | 중립 무대 | 추상 소프트 그라디언트/스튜디오 — 분야 불명 시 기본. 미니멀. |

> 추가 장면은 나중에 같은 규격으로 늘리면 코드가 자동 인식(레지스트리에 1줄 추가). 우선 6장.

## 폴백 (에셋 없어도 앱은 동작)

- 컷아웃 없음 → 기존 반신 `portraits/{id}.webp`(배경 박힌 것) → 그것도 없으면 `PersonaOrb`(아이콘/이니셜).
- 배경 없음 → 기존 `--stage-bg` 그라디언트(⑤-2b).

즉 **에셋은 점진 투입 가능** — 1장씩 올려도 그만큼 무대가 살아남. 코드(⑤-5h)는 에셋 0개여도 폴백으로 머지/배포된다.
